# PlantCare 🌱

PlantCare adalah mini program sederhana berbasis Python yang digunakan untuk
mencatat tanaman dan mengetahui jadwal penyiraman berikutnya.

Program ini dibuat untuk memenuhi tugas Pertemuan 3 mata kuliah
Analisis & Pengujian Sistem, yaitu menemukan defect/fault pada sebuah
program dan melakukan Root Cause Analysis (RCA).

## Fitur

Program PlantCare memiliki beberapa fitur:

1. Menambahkan data tanaman
2. Melihat daftar tanaman
3. Mengecek jadwal penyiraman
4. Mencari tanaman berdasarkan nama
5. Keluar dari program

## Teknologi

- Bahasa pemrograman: Python
- Penyimpanan data: List dan Dictionary
- Interface: Command Line / Console
